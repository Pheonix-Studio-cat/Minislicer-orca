How printing works

Bambu Connect runs on Windows and macOS only. Start the Minislicer Runner on the computer that has Bambu Connect, scan the QR code it shows, and this page gains a Print with Bambu Connect button. The runner hands the sliced file to Bambu Connect, where you pick the printer and confirm.

Without the runner you can still slice and download the .gcode.3mf, then open it in Bambu Connect yourself.
