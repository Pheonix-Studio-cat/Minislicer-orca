About

Bambu Connect runs on Windows and macOS only. Start the Minislicer Runner on the computer that has Bambu Connect and scan its QR code; Print plate then hands the sliced file to Bambu Connect, where you pick the printer and confirm. Without the runner, use the arrow next to Print plate to export the file.
